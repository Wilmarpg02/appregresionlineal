Comparador de modelos

Carga tus datos, elige una variable objetivo y uno o más predictores. El aplicativo evalúa todas las combinaciones posibles y compara su desempeño en datos de validación.

PASO 1

Carga el archivo de datos

El archivo se procesa en este navegador
Selecciona un archivo para comenzar

Se usa la primera hoja si cargas un libro de Excel.

Formatos compatibles: Excel .xlsx y archivos delimitados .csv, .tsv o .txt. Los archivos .xls antiguos deben guardarse primero como .xlsx.

Vista previa

PASO 2

Selecciona las variables

La variable Y debe contener valores numéricos.

Marca las variables que quieres incluir. El aplicativo genera modelos para todas las combinaciones no vacías de las X seleccionadas.

Las columnas categóricas se codifican con indicadores (categoría base omitida). Con interacciones activas, cada modelo incluye los efectos principales y los productos por pares de las variables incluidas en ese modelo.
RESULTADOS

Desempeño de los modelos

La tabla se ordena por el menor MAE de validación. Un menor MAE/MSE indica menos error; un R² más alto indica mayor proporción de variación explicada.
Herramienta autocontenida. No envía ni almacena tus datos fuera del navegador.
